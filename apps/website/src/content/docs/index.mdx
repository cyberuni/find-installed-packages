`find-installed-packages` answers one question: which installed packages declare these keywords in
their `package.json`?

```ts
import { findByKeywords } from 'find-installed-packages'

const packages = await findByKeywords(['some-keyword']) // ['pkg-a', 'pkg-b']
```

It finds them by walking the declared dependency graph and asking the runtime's module resolver where
each package lives, so the answer is the same under npm, yarn, bun, pnpm, workspaces, and Yarn
Plug'n'Play.
